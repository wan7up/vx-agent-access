# 兼容性与回退

公开源码基线：`vx-agent-access-20261007-r5`。
这是一份实际部署提炼出的工程参考，不是任意设备或版本组合的兼容性保证。

## 验证范围

- Linux ARM64 Armbian 上部署过 OpenClaw 文字与小智双向通话。
- 2026 年 10 月 7 日已有手机私聊、群聊和真实语音通话实测。
- 本地回归覆盖桌面入口、探针、文字辅助程序、通话控制、小智协议和音频清理。
- 当前小智后端不需要 Codex CLI 或 WebRTC。旧 Codex 后端仅作历史参考。
- 未在干净的新主机完成整套公共指南复现；不能据此宣称一键安装或全面支持 amd64。

## 桌面依赖

数据库消息读取、客户端登录、agent-server 解密密钥、无障碍树和真实发送
是不同环节。认证接口成功或消息可读不等于文字能发出，语音设备在线也不等于
通话音频已接入。验收必须从手机发送新消息并收到对应回复，再完成双向通话。

重建参考用一个桌面用户、一套 D-Bus/AT-SPI 和 PulseAudio 会话，避免不同用户
工具操作不同桌面。运行时 socket 放在临时目录，不随 HOME/data 卷持久化。

`a11y-dump-wrapper.py` 对无障碍扫描使用有限锁等待和执行超时：
默认最多等锁 3 秒、扫描 5 秒。并发过高仍可能返回 `unknown`，这是明确的
容量边界，不应以增加超时或持续叠加探针掩盖。重复叠加镜像保留原始 probe。

容器 `init: true` 回收孤儿进程，但不替代上游程序回收自己的直接子进程。
上游 agent-server 的子进程处理及健康检查行为需按实际二进制版本单独验证。
本仓库不提供该二进制，也不声称所有上游缺陷已经修复。

## 音频生命周期

通话播放流/麦克风流出现后才能转发。云端建链可能很快，桌面音频初始化仍可能
延迟数秒。不要把接听点击、小智 WebSocket 连接与可对话时间混为一谈。

每通音频进程使用独立 owner；挂断、失败和取消只清理该 owner 的 `parec`/
`pacat`。Bridge 单元的 `ExecStopPost` 在异常退出时再次执行幂等清理。
必须成套安装共享模块、Bridge 和单元文件，不用全局 kill 或定时扫杀代替。

小智音频就绪后发送一次“你好”，本地不注入群历史或人设。长回答中途无声
应分别检查服务返回音频、播放缓冲、音频路由与客户端，不能仅凭后台文字
就认定云端或客户端是哪一方故障。

## 升级与回退

1. 在没有通话时记录镜像 digest、二进制 hash、依赖版本及配置。
2. 私有备份 HOME/data 卷、Agent 配置、设备身份和相应镜像。
3. 候选容器使用独立卷与 loopback 端口，不先挂真实账号数据。
4. 确认二进制与数据库 schema 匹配；升级过的数据库不可随意挂给旧二进制。
5. 逐层验证认证、非空聊天列表、真实文字收发、语音和挂断清理。
6. 出现异常时恢复成套镜像与数据，而不是删卷重新试；先停辅助服务避免重复动作。

公开模板没有包含维护者的生产镜像、密钥或回退包。不要把公共示例直接当作
已登录设备的完整恢复方案。
