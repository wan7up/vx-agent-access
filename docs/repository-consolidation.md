# 仓库整合与公开边界

项目统一使用 **vx agent接入**，GitHub 仓库名为 `vx-agent-access`。
当前 OpenClaw 文字链路、小智 Bridge、共享音频模块、通话控制和回归测试
在一个仓库维护；旧 Codex Voice 实现在 `archive/codex-voice/`。

## 公开内容

- 架构、设备条件、分步部署流程和实现场景。
- 通用源码、配置占位符、合成测试数据和第三方参考链接。
- 脱敏后的兼容性、故障边界与回退原则。

## 不公开内容

- 联系人、群标识、聊天记录、音频、截图及角色私人背景。
- 设备身份、登录态、密钥、模型凭据与真实部署配置。
- 私人主机盘点、现场日志、恢复包和旧 Git 历史。

旧仓库曾包含私人部署记录，不能只在最新提交中删除后就改为公开。
公开版使用全新历史；原始源码和完整历史仅保留在维护者本机私有备份。
不把旧提交、tag、bundle 或备份上传为公开资产。

这是文档和源码整合，不是生产升级。已有部署的镜像、卷名、路径和参数
不因公开示例变化而改变；不要把示例 Compose 直接覆盖到现网。
