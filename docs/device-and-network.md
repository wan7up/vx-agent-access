# 设备与网络

## 主机条件

当前有实机记录的是一台 RK3399 / ARM64 Armbian 主机，文字和语音均
部署在 Linux 上，Mac 只用于维护，不需要一直开机。

新设备建议使用支持 systemd 的 Linux。选择前确认：

- CPU 架构有可用的 Linux VX 包、agent-wechat 容器及音频依赖。
- Docker 和 Compose 能运行，数据卷位于持久存储。
- 可长期开机，有可靠供电、散热与足够空闲存储。
- SSH 可管理，扫码登录及异常处理时能访问容器桌面。
- 初期不要与路由等关键服务共用一台资源紧张的主机。

规划建议是 4 GB 内存起步、8 GB 或更多较宽裕，至少预留约 20 GB 可用存储；
这不是经基准测试确定的最低配置。多 Agent、大模型本地推理、图片任务、
长历史和其他容器都会改变需求。文字和语音模型可以在云端，不要求本机 GPU。

不要因为 CPU/内存平均使用率低就忽略生命周期问题：容器可能先耗尽
进程/线程额度。检查僵尸进程、`pids.events`、OOM 与重启次数同样重要。

## 图形和音频

虽然主机可以没有实体显示器，但容器仍需要图形桌面：

```text
Xvfb -> 桌面窗口 -> D-Bus / AT-SPI -> VX 控件操作
                         PulseAudio -> 音频采集 / 注入
```

虚拟音频设备承担通话收听和麦克风输入，不需要接实体麦克风或音箱，
也不需要小智 ESP32 硬件。容器用户、D-Bus、AT-SPI 与音频会话必须一致。
启用 init 回收孤儿进程，但程序也必须回收自己启动的直接子进程。

基础文字部署从上游客户端开始，不要直接使用本仓库
`deploy/desktop-rebuild/compose.yaml`；它要求自行提供匹配的镜像、二进制与外部卷。

## 账号条件

| 账号/凭据 | 用途 |
| --- | --- |
| VX 个人号 | Linux 桌面扫码登录，保存登录态和数据库密钥 |
| 文字模型服务凭据 | OpenClaw 请求模型；与小智设备身份独立 |
| 小智账号和已绑定虚拟设备 | 当前语音后端；语言、角色和音色在后台设置 |
| 官方 Codex 账号 | 仅选择归档的旧 Codex Voice 后端时需要，当前小智版不需要 |

建议使用专门测试号；自动接听不能可靠识别来电所属群，不能用文字
allowlist 约束全部来电。首次扫码和异常重新登录通常需要人配合。
只在客户端 GUI 登录，不一定同时恢复 agent-server 的数据库解密状态，
应按上游正式登录流程验证。

## 长期网络需求

文字和语音不在本机离线推理，运行时需要持续联网：

1. VX 客户端连接其消息及通话服务。
2. OpenClaw 连接配置的文字模型和工具服务。
3. 小智 Bridge 访问设备激活/OTA 与语音 WebSocket。
4. 部署或更新时需要 GitHub、容器镜像及包源。

已有可用代理即可，不强制 Tailscale，也不要求公网 IP。局域网用于 SSH
维护；代理用于访问不可直达的外部服务，两者不是同一件事。

小智版重点验证 HTTPS/WSS、DNS、时间和长连接。旧 Codex Voice 还需要
验证 WebRTC/ICE 媒体路径，HTTPS 可达不能证明 UDP 媒体可用。
不要为了一个服务的联网改动整台主机默认路由；先确认现有网关、DNS、
代理方式和容器网络，避免破坏其他服务。

## 端口与数据

- agent-wechat 的 REST API 和缓存代理只绑定本机 `127.0.0.1`。
- SSH 或桌面访问仅用于管理，不向公网暴露 Agent 控制接口。
- 不开放 App Server、无认证 VNC 或公开反向代理。
- token、设备身份、VX HOME/data、OpenClaw 会话和回退档案保留在私有位置。
- 系统时间应保持同步；日志同时记录时区，以便对齐拨号、接听和音频时间。

本仓库的 `6174`、`6175`、`6274` 是参考端口，不是外网服务端口。
私有 GitHub 仓库也不适合保存账号登录态或密钥。

## 初次验收

先完成文字，再增加语音：

1. 带认证的真实 API 返回 `logged_in`，聊天列表非空。
2. 手机发送新的私聊和群内 mention，实际收到对应回复。
3. 小智设备单独可建链、识别和播放。
4. 实际 VX 通话完成多轮双向语音，挂断后清理本次音频进程。
5. 在保存快照后验证容器重启及主机正常重启的恢复。
6. 连续观察，确认没有僵尸堆积、进程额度事件、OOM 和重启风暴。

`active`、容器 `running`、数据库能读、设备在线都不能单独代替这些验收。
